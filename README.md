## Proyecto destacado: Quirón
Plataforma escolar que conecta a la escuela con las familias. Los maestros pasan lista, capturan calificaciones y publican avisos desde un panel web, y las familias siguen el progreso de sus hijos en una app móvil, sin comparaciones entre estudiantes.

- **Demo en vivo:** [panel web](https://quiron-panel.onrender.com) · [app para Android](https://github.com/felixarvizuangel/proyecto-quiron/releases/latest)
- **Código:** [proyecto-quiron](https://github.com/felixarvizuangel/proyecto-quiron)
- **Stack:** Node.js · TypeScript · Express · PostgreSQL · React · Tailwind CSS · Flutter · Docker
- **Incluye:** permisos por rol verificados en el servidor, 16 pruebas automatizadas, integración continua con GitHub Actions y despliegue en Render y Neon.
